## Abstract / 摘要
The **Spatial Pressure Gravitational Theory (SGT)** is an original, self-consistent, fundamental theory of gravity based on continuum medium dynamics. It proposes that all space is filled with an invisible, elastic, and universal medium—the **Spatial Pressure Medium**. Gravity is not attraction; it is a **net pushing force** caused by the tension gradient (Spressure) generated when matter displaces the medium.

空能引力理论（SGT）是一套基于连续介质动力学的原创、自洽、基础引力理论。该理论提出：宇宙中充满一种不可见、具有弹性、全域均匀的介质——**空能介质**。引力并非物质间的“吸引”，而是物质排挤介质后形成的**张力梯度推力**。
